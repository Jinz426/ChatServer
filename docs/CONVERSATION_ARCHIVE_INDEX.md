# Conversation Archive Index

## Purpose

This index organizes the long-running ideas developed across the user's ChatGPT conversations into a research map. It is an index of themes and recovered context, **not a claim that it contains every historical message verbatim**. A complete verbatim archive requires the user's ChatGPT data export or the original conversation files.

## 6. Evidence / Forensic Method

The conversation evolved toward combining global observation with forensic-style reasoning:

`observation → evidence → hypothesis → independent corroboration → alternatives → conclusion → revision`

Every data point should distinguish:

- Observed
- Sourced
- Derived
- Inferred
- Unknown

Agreement between AI models is not proof. Correlation is not automatically causation.

## 7. AI-Readable Global History

The desired "通史" is not only chronology. It connects:

`time × space × people × resources × technology × institutions × economy × environment`

Historical events can therefore be connected to land, food, energy, materials, transport, production, population, trade, technology and institutional change.

The goal is a living, versioned knowledge graph that can be revised when better evidence appears.

## 15. Important archival boundary
